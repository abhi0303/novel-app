# Kamra Number 7: scene images

The 30 scene images are realistic, cinematic stills. They replaced the original hand-drawn SVGs, with the same scene ids and the same content, so the chapters did not change. Each is a 1280×720 WebP in `src/stories/kamra-number-7/scenes/`; the file name is the scene id used by the chapters.

They were generated on [AI Horde](https://aihorde.net) with an anonymous key, using two models at 1024×576:

- **Juggernaut XL** (SDXL): 30 steps, CFG 5.5, `k_dpmpp_2m` with Karras. Used for most scenes with people and for atmosphere.
- **Flux.1-Schnell**: 4 steps, CFG 1, `k_euler`. Used where the picture has to follow the brief closely (object layouts, clocks, both CCTV stills, the arrival and epilogue).

Every prompt starts with the style prefix `cinematic film still, realistic photography, 35mm, muted moody colour grade, soft film grain, high detail`. The negative prompt is `cartoon, anime, illustration, painting, drawing, cgi, 3d render, lowres, blurry, deformed, bad hands, extra fingers, watermark, logo, signature, nsfw, nude, gore, blood`.

On top of the shared descriptions:

- **The four suspects' faces** are generated once, as portraits, and reused. `four-suspects` frames those portraits and `case-board` pins the same faces as instant photos, so the faces are identical in both. Arjun's interrogation image was chosen because it matches his portrait.
- **Dev and Kabir** are shown from behind, as in the original drawings: Dev grey-haired in a long charcoal coat, Kabir in a navy padded jacket and scarf. `arrival-dawn` and `mussoorie-morning` match. The man at the window in `dining-room` is Dev's silhouette.
- **People who must not be identified** (the man under the red umbrella, the shadow in the pantry, Meera seen from behind in the corridor) are never shown with a face.
